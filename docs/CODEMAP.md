# Mapa del código

Qué archivo editar para cada cambio. Cada archivo de `src/` tiene 300 líneas como máximo y un solo tema (reglas en [`conventions.md`](conventions.md)). Cada tabla dice «Para cambiar…» → «Edita».

| Área | Mapa |
| --- | --- |
| Página, layout, tokens, HUD, secciones, textos y contenido | [`codemap/web.md`](codemap/web.md) |
| Navegación por planos, texto cinético y sonido | [`codemap/motion-audio.md`](codemap/motion-audio.md) |
| Motor 3D: cargador, Stage, director, scroll, placas, interacción, tier | [`codemap/stage.md`](codemap/stage.md) |
| Escritorio 3D: encuadres, luz, props, figuras, carpetas, pantallas | [`codemap/desk.md`](codemap/desk.md) |
| Postproceso y fluido | [`codemap/fx.md`](codemap/fx.md) |
| Página 404 | [`codemap/notfound.md`](codemap/notfound.md) |

Si agregas, mueves o borras un archivo, actualiza su fila en el mismo commit.
